# Учебная практика по Python

Практические работы за 1 курс, специальность 09.02.13.
Дни 1-10: от основ синтаксиса до анализа данных в Pandas и построения графиков.

## Состав

| Папка | Тема |
|---|---|
| `day01` | Основы Python, виртуальное окружение, colorama |
| `day02` | Типы данных и ввод с клавиатуры |
| `day03` | Условия, логические операторы |
| `day04` | Списки и словари |
| `day05` | Циклы и работа с файлами |
| `day06` | NumPy: одномерные массивы |
| `day07` | NumPy: двумерные массивы |
| `day08` | Pandas: Series и DataFrame |
| `day09` | Pandas: CSV, фильтрация, сортировка, пропуски |
| `day10` | Pandas: groupby и Matplotlib |

В каждой папке лежат файлы по заданиям методички, итоговый файл `final_dayN.py`
и результаты работы: CSV, TXT и PNG.

## Запуск

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

python day10\task01_mean_by_group.py
```

Скрипты сами переходят в свою папку, поэтому запускать их можно из корня проекта.
Файлы с графиками открывают окно с диаграммой, а также сохраняют PNG рядом с собой.

## Версии

- Python 3.13
- pandas 3.1.1
- matplotlib 3.11.2
- numpy 2.5.5
