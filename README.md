# Практика по Python

Практические работы за октябрь-ноябрь.

Все задания находятся в папке `Практика`. Запускать файлы нужно из папки нужного дня, например:

```
cd Практика/day10
python task01_mean_by_group.py
```

Для дней 9 и 10 нужны библиотеки pandas и matplotlib:

```
pip install pandas matplotlib
```
